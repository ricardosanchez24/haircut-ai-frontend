# Features

Cada feature tiene su propia carpeta con:

- `spec.md` - Qué hace la feature y criterios de aceptación
- `plan.md` - Cómo se implementa
- `tasks.md` - Checklist de tareas

## Estructura de una feature

```
NN-nombre-feature/
├── spec.md    ← QUÉ hace
├── plan.md    ← CÓMO se implementa
└── tasks.md   ← Checklist de tareas
```

## Naming

Usar formato: `NN-nombre-feature`
- Ejemplo: `01-setup-proyecto`
- Ejemplo: `02-upload-imagen`
- Ejemplo: `03-integracion-api`
