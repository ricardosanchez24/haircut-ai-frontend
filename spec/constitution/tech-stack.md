# Tech Stack

## Frontend
- **Framework:** React + Vite
- **Estilos:** Tailwind CSS
- **Iconografía:** Lucide Icons (lucide-react)
- **HTTP:** fetch nativo o axios
- **Router:** No se usa (SPA con estados)

## Backend
- **Framework:** FastAPI (Python)
- **IA:** Google Gemini
- **URL:** http://localhost:8000/api

## Endpoints
- POST /api/analyze (multipart/form-data)

## Convenciones
- Sin react-router-dom
- Estados de React para navegación
- Validaciones en cliente (JPG/PNG, max 10MB)
- 100% responsive con Tailwind
