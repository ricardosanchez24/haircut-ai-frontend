# Roadmap

## Orden de features (MVP)

### Fase 1: Estructura base
1. Setup del proyecto (React + Vite + Tailwind)
2. Componente Header
3. Componente Footer

### Fase 2: Upload
4. Componente de upload de imagen
5. Validaciones en cliente (formato, tamaño)
6. Vista previa de imagen

### Fase 3: Análisis
7. Integración con API (envío de imagen)
8. Estado de loading con mensajes dinámicos
9. Manejo de errores de red

### Fase 4: Resultados
10. Pantalla de resultados (3 cortes)
11. Componente de recomendación (nombre, icono, descripción)
12. Texto "cómo pedirlo al barbero"
13. Botón "intentar con otra foto"

### Fase 5: Pulido
14. Estados de error (foto mala, API falla, sin conexión)
15. Responsive design completo
16. Pruebas básicas
